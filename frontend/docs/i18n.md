# FE-06: language foundation

Owner: Zayid. [Trello card](https://trello.com/c/Lklfq7fO).

The header offers English, Arabic, Azerbaijani, Turkish and Russian in their native names. A supported saved choice wins; otherwise browser preferences are checked in order, then English. Storage failures retain a tab-only choice. Switching preserves the route/session and updates `html.lang` and `html.dir`. FE-08 owns the full RTL layout audit.

`src/i18n/<language>/common.json` contains the translated shell. Add feature namespaces and their five resource files when implementing FE-07; English is the source and runtime fallback. React escapes text. Full domain-screen and legal translations are not claimed here.

Use `useTranslation()` for text and `formatNumber` / `formatDate` for display values. API requests, including token refresh, send the current `Accept-Language`; an explicit per-request header wins. Backend translation is a separate capability, so this does not claim server errors are translated.

`npm run i18n:check` fails CI for missing resource files/keys and reports hard-coded JSX text and accessible labels as the FE-07 migration inventory. Existing literals are warnings, not silently described as translated. The scan does not replace a human audit of strings assembled in JavaScript.

Validation: language selection, denied storage, locale fallback, RTL/LTR, number/date formatting, selector events and request headers have regression tests. Review the header at desktop and 360px and switch Arabic back to English before merge. Human translation review remains necessary before the final language module demo.
